# 1021project - 王瑋呈 個人自我介紹 & 履歷網頁

王瑋呈的個人自我介紹與履歷單頁式網頁，風格採用**日系簡約 × 冰藍科技感**。

## 🌟 網頁特色
- **無框架設計**：單一檔案 `index.html`，純 HTML、原生 CSS 與輕量 JavaScript。
- **色彩風格**：天藍色 (`#38bdf8`) 與冰藍色 (`#a5f3fc`)，搭配深邃冷色調科技背景與發光霓虹光暈。
- **動態效果**：原生 `IntersectionObserver` 捲動平滑淡入動畫。
- **響應式排版**：電腦、平板與手機螢幕全適配。

## 📌 個人資訊涵蓋
- **基本資料**：王瑋呈（高中三年級在讀學生）
- **三大興趣**：看小說、玩遊戲、看動畫
- **技能與學習目標**：程式架構思維、現代網頁設計、資訊科學基礎
- **經歷活動**：電機與資訊相關科系探索營隊

## 🚀 如何開啟
直接以任何現代瀏覽器（Google Chrome, Microsoft Edge, Safari, Firefox）開啟 `index.html` 即可瀏覽。
